# Documentação do Projeto - Sistema de Barbearia

Esta branch reúne os documentos de apoio do projeto **Sistema de Barbearia**, desenvolvido com foco na organização dos requisitos, regras de negócio, estrutura do sistema e validação da API.

## Conteúdo da documentação

Nesta branch estão reunidos documentos como:

- **Requisitos do sistema**  
  Descrição das funcionalidades esperadas, regras de negócio e necessidades principais do sistema.

- **Casos de uso**  
  Representação das ações que os usuários podem realizar, como cadastro, login, gerenciamento de serviços e agendamento.

- **Diagrama de classes**  
  Estrutura das principais entidades do sistema, como usuário, perfil, serviço e agendamento.

- **Diagramas do sistema**  
  Representações visuais que ajudam a entender a arquitetura e o funcionamento geral da aplicação.

- **Documentação de endpoints**  
  Lista das rotas da API, seus métodos, permissões, descrições e exemplos de requisições.

- **Documentação de testes de API**  
  Registro dos testes realizados com o Postman, incluindo autenticação, permissões, validações e regras de negócio.

## Objetivo

O objetivo desta branch é centralizar toda a documentação do projeto, facilitando a consulta, manutenção e evolução do sistema durante o desenvolvimento.

## Observação

A documentação pode ser atualizada conforme novas funcionalidades forem adicionadas ou alterações forem feitas no projeto.
